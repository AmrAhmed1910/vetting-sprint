# Vetting Sprint

A 30-day, 2-hours-a-day job-readiness tracker for remote engineering platforms (micro1, Turing, Crossover, Arc).

Installable web app: open https://amrahmed1910.github.io/vetting-sprint/ on your phone and choose **Add to Home Screen** / **Install app**. Works offline. Progress is stored on the device; use Settings → Backup to move it.
